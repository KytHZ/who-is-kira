# Who Is Kira?

A Death Note fan deduction game for 4 to 10 people, played by passing one phone around the table. One player is secretly Kira, one is L, and everyone else is Task Force.

Open `who-is-kira.html` in a browser to play. There is nothing to install.

Run the rules check with `node check.js`.

This is an unofficial fan project, not affiliated with the Death Note creators or publishers.
